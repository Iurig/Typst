Set and show rules

Lesson 2 · the preamble you never have to copy again, and the LaTeX look in eight lines

~30 minutesBuilds on Lesson 1Reference: Set & show rules

In Lesson 1 you wrote #set math.equation(numbering: "1.") in the middle of your file and it worked. This lesson explains why, where it would not have worked, and how the same mechanism replaces most of the thesis preamble: lmodern, indentfirst, setspace, geometry, chapter page breaks. At the end your Lesson 1 translation will be indistinguishable from LaTeX output.

Set rules are default arguments

Every element in Typst is a function: text, par, page, heading, list. Calling one directly styles one thing: #text(red)[warning]. A set rule changes the function's defaults for everything that follows (styling reference):

// every text from here on
#set text(font: "New Computer Modern")
// every heading from here on
#set heading(numbering: "1.1")

Only optional parameters can be set, which is why you never write #set heading[Title]. The LaTeX guide's phrase is the one to remember: set rules "can be thought of as default argument values" (guide).

Scope: from here to the end of the block

A rule applies from the line it is written on to the end of the enclosing block. At the top level, that is the end of the file. Inside […] or {…}, it ends with the bracket. Two consequences:

  • Rules don't reach backwards. Your Lesson 1 set rule came after the first heading, so if it had been #set heading(numbering: "1.1"), that heading would have stayed unnumbered. Typst has no preamble; the top of the file is the preamble.
  • Brackets are a scoping tool. Want dashes for one list only? Wrap the rule and the list together: 
#[
  #set list(marker: [--])
  - dashed
]
- bulleted again

The #[ … ] is a content block entered from markup via a hash. You met the same brackets in Lesson 1 as the argument of #strong[…].

Show rules are hooks on elements

When arguments are not enough, a show rule intercepts every element matching a selector. It comes in three flavours (styling reference):

show-set: a set rule, but only inside headings

#show heading: set block(above: 1.4em, below: 1em)
#show raw: set text(font: "New Computer Modern Mono")

show + function: rebuild the element; it is the element

#show heading.where(level: 1): it => {
  // chapters start on a new page
  pagebreak(weak: true)
  // then the heading itself
  it
}
// show everything: the \documentclass of Typst
#show: conf.with(title: [Higher-degree EGZ])

Selectors can be an element (heading), an element with fields (heading.where(level: 1)), a string (show "Erdős": smallcaps), a regex, or a label. The function form is the \renewcommand replacement: inside, it has fields named after the element's parameters, such as it.body and it.level.

One gotcha from the docs: a set inside a show function cannot be overridden by a later show-set rule. Keep styling in show-set rules where you can, and reserve the function form for structural changes like the page break.

The LaTeX look

The official guide gives the recipe ("How do I get the LaTeX look?"). Read it as four set rules and three show-set rules, nothing more:

#set page(paper: "a4", margin: 1.75in)
#set text(font: "New Computer Modern", size: 11pt)
#set par(justify: true, leading: 0.55em, spacing: 0.55em,
         first-line-indent: (amount: 1.8em, all: true))
#show raw: set text(font: "New Computer Modern Mono")
#show math.equation: set text(weight: "regular")
#show heading: set block(above: 1.4em, below: 1em)
  • leading is the space between lines, spacing between paragraphs. Equal values give the LaTeX \parskip=0 feel.
  • first-line-indent: 1.8em alone behaves like plain LaTeX: the first paragraph after a heading is not indented. Your thesis loaded indentfirst; the dictionary form with all: true is that package.
  • Typst embeds New Computer Modern and its Math font. The Mono variant was missing on your machine; it is now installed in ~/.local/share/fonts, copied from your TeX Live tree.

Check yourself

From memory.

A #set heading(numbering: "1.1") written after the first heading. Is that heading numbered?

Rules apply from where they are written to the end of the enclosing block. Earlier content is untouched.

#show heading: set text(navy) is which kind of rule?

A set rule applied only inside the selected elements. The most composable form; prefer it over a function when it suffices.

How do you make a set rule affect one list and nothing after it?

A content block #[ … ] ends the rule's scope. There is no "unset".

In #show heading: it => …, what is it?

The whole element. Its fields are it.body, it.level, it.numbering. Returning it keeps it unchanged.

What replaces \documentclass{article}?

#show: conf.with(…) passes the rest of the document through the template function. Lesson 7 builds one.

With first-line-indent: 1.8em alone, which paragraph is not indented?

Same convention as plain LaTeX. (amount: 1.8em, all: true) is the indentfirst equivalent.
