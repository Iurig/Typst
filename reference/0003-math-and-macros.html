How a name in math is read

You writeTypst readsResult
$x y$two single lettersitalic x y
$xy$a variable named xyerror unknown variable: xy unless defined
$ZZ$, $sum$a built-in nameℤ, ∑
$"char"$literal textupright, text spacing (\text)
$#v$the variable vits value; the hash is needed because v alone is a letter
$f(a, b)$a call when f is a function namecommas separate arguments; \, is a literal comma

Macro patterns

LaTeXTypst
\newcommand{\Zb}{\mathbb{Z}}#let Zb = $ZZ$
\DeclareMathOperator{\egz}{EGZ}#let egz = math.op("EGZ")
\DeclareMathOperator*{\argmax}{arg\,max}#let argmax = math.op("arg max", limits: true)
\newcommand\inner[2]{\langle #1, #2 \rangle}#let inner(a, b) = $lr(chevron.l #a, #b chevron.r)$
\pmod{p}#let pmod(n) = $quad (mod #n)$
\newcommand{\equals}[1][]{\stackrel{#1}{=}}#let equals(by: none) = $limits(=)^#by$
call: equals(by: "def")

Inside a $…$ body, every one-letter parameter needs #. Without it the letter is printed and no error is raised.

Name clash: Typst's Re / Im are ℜ / ℑ. For the upright operators, define #let Re = math.op("Re"), which shadows the built-in from that line on.
