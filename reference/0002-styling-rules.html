Set & show rules

Reference 0002 · the Typst replacement for preamble packages, \renewcommand and \setlength

The four forms

FormSyntaxMeaningLaTeX analogue
set#set text(font: "New Computer Modern")change a function's default arguments from here onpackage options, \setlength
set-if#set text(red) if draftset only when a condition holds\ifdraft
show-set#show heading: set text(navy)set, but only inside the selected elementstitlesec-style tweaks
show + function#show heading.where(level: 1): it => { pagebreak(weak: true); it }replace each selected element with what the function returns; it is the element\renewcommand, \let\old…
show everything#show: template.with(title: [T])pass the rest of the document through a function\documentclass

Scope

  • A rule applies from the line it is written on until the end of the enclosing block: the file, a content block […], or a code block {…}.
  • It never reaches backwards. A #set heading(numbering: …) written after a heading leaves that heading unnumbered.
  • To scope a rule on purpose, wrap it with its content: #[ #set list(marker: [--]) - a - b ].
  • Put document-wide rules at the top of the file. Typst has no preamble; the top of the file is the preamble.

Inside a show function

  • it is the element. Return it to keep it, or build something new around it.
  • Fields match the function's parameters: it.body, it.level, it.numbering.
  • A code block {…} joins the values it produces: { pagebreak(weak: true); it } outputs both.
  • Gotcha: a set inside a show function cannot be overridden by a later show-set rule. Prefer separate show-set rules when you can.

The LaTeX look (official recipe)

#set page(paper: "a4", margin: 1.75in)
#set text(font: "New Computer Modern", size: 11pt)
// all: true is the indentfirst package
#set par(justify: true, leading: 0.55em, spacing: 0.55em,
         first-line-indent: (amount: 1.8em, all: true))
#show raw: set text(font: "New Computer Modern Mono")
#show math.equation: set text(weight: "regular")
#show heading: set block(above: 1.4em, below: 1em)
#set heading(numbering: "1.1")
#set math.equation(numbering: "(1)")

leading is the gap between lines, spacing the gap between paragraphs. LaTeX uses the same value for both when \parskip is zero, hence 0.55em twice. Typst's defaults (0.65em leading, 1.2em spacing) are the "web" look.

Numbering patterns

A pattern is read as counting symbols (1 a A i I …), each with the text in front of it as its prefix. Everything after the last counting symbol is the suffix. One symbol is used per level. If there are more levels than symbols, "the last counting symbol with its prefix is repeated" (numbering reference). So the dot in "1.1" is the prefix that gets repeated, and "1" has an empty prefix: section 1.1.2 prints as 112.

PatternOutput
"1"1, 11, 112 (no separator to repeat)
"1.1"1, 1.1, 1.1.2
"1.a"1, 1.b, 1.b.c (last symbol repeats)
"I.1"II, II.3
"1.1."1., 1.1.
"(1)"(1), (2)
"I." / "a)" / "①"Roman, letter, circled
