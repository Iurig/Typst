Preamble: the thesis setup

#import "@preview/ctheorems:2.0.0": *
#import thm-themes.ams: *
// default ∎ = your \blacksquare
// (amsthm's □: thm-rules.with(qed-symbol: $square$))
#show: thm-rules

#set heading(numbering: "1.1")

// [chapter]: Theorem 1.2, not 1.1.2.
// Shared counter: same base-level everywhere.
#let theorem = theorem.with(base-level: 1)
#let lemma = lemma.with(base-level: 1)
#let proposition = proposition.with(base-level: 1)
// \newtheorem{definition}{Definition}[chapter]
#let definition = definition.with(
  counter: "Definition", base-level: 1,
)
// \newtheorem*{theorem*}{Theorem}
#let theorem-plain = theorem.with(numbering: none)
// corollary [theorem] (1.2.1) is the default

Using environments

LaTeXTypst
\begin{lemma} … \end{lemma}#lemma[ … ]
\begin{theorem}[Euler] …#theorem[Euler][ … ] (two brackets: name, then body)
\label{chev}#theorem[ … ] <chev> (after the closing bracket)
\cref{chev}@chev → "Theorem 1.2"
\begin{proof}[Proof of …]#proof[of @chev][ … ] → "Proof of Theorem 1.2."
\qedhere#qedhere as the last thing in a display equation or list item
\tag{AM-GM}#tag[(AM-GM)] inside an unnumbered display

One bracket is always the body: #theorem[Euler] is a theorem whose statement is "Euler".

Numbering options

OptionMeaningDefault
basewhat prefixes the number: "heading", another counter name, or none (plain 1, 2, 3)"heading"
base-levelhow many levels of the base to keep; none keeps allnone
countercounter name; environments with the same name share a countthe supplement
numberinga numbering pattern, or none"1.1"
supplementthe word: "Theorem", "Teorema"…per environment

How a number is built

The number is the pattern applied to (base levels…, count). The pattern rules are in reference 0002, Numbering patterns.

WhereOptionsValuesPrints
3rd theorem in §2.1defaults(2, 1, 3)2.1.3
3rd theorem in §2.1base-level: 1(2, 3)2.3
3rd theorem in §2.1base-level: 1, numbering: "1"(2, 3)23
3rd theorem in §2.1base-level: 1, numbering: "I.1"(2, 3)II.3
3rd theorem, anywherebase: none(3)3
  • Environments sharing a counter need the same base and base-level. When the base changes between two of them, the count restarts at 1.
  • Unnumbered headings are not counted. Without heading numbering you get Theorem 0.1, 0.2… In notes with no chapters, use base: none.
